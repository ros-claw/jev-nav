# LIMO 无预建地图自主探索设计

## 目标

机器人从实时相机、深度、激光与里程计观测出发，在未知的室内环境探索；不要求用户事先建图或提供导航目标。Decisions API 从机器人当前场景和有限动作中选择下一步，机器人执行短暂动作后重新观察。允许机器人维护短期局部几何和探索记忆，但不要求事先存在全局地图。用户可在现场随时停止任务。

## 路线与取舍

1. 依靠现有地图导航：实现快，但要求匹配的预建地图，不符合目标。
2. 无预建地图的分段视觉决策：模型选择前进、左转、右转或停止等有限动作，由本地几何和运动执行器约束并核验。满足自主探索目标，也允许在网络迟滞时及时停车。**采用此路线。**
3. 模型连续直接输出任意速度：无法仅靠云端保证低延迟或盲区安全；作为首版实机路线不可接受。

模型承担动作选择，不把选择概率当成碰撞安全概率。短期局部占据表示和探索记忆只由机器人自动生成，不依赖人工建图。候选动作的可视化仅在标定和时间同步可靠时显示为几何轨迹，否则明确标注为示意。

## 实现范围

- 静态和录制数据验证：采集带时间戳的观测，检查相机、深度、雷达、里程计、TF、标定和有效视野；验证 Decisions API 的图像输入、选项、拒答、延迟和错误处理。任何录制和展示应避免泄露 API 密钥。
- 构造与当前轮型、底盘模式一致的有界短动作候选，含停止。检测车体轮廓及运动扫掠区域，未知、过期、无法覆盖或碰撞的空间不能当作可通行。结合深度、激光和同步性；缺少可验证的有效观测时停住。
- 为无地图任务新增 ROSClaw 守护进程侧的正式执行能力和任务契约，不从 Agent 直接发布 `/cmd_vel` 或访问驱动。执行器须有独立于云端的连续避障、限速、时限、租约/看门狗、失联停车和物理急停链，并在每步输出回执及里程计证据。其真实设备可执行性必须单独验证，不能从静态契约推断。
- 用一次任务授权绑定明确的活动范围或可验证的其他空间限制、时间上限、速度上限和停止条件；当前只支持单目标确认，不能把它解释成连续任务授权。任务结束、授权失效或传感器故障时停车。
- 将每次候选与观测时间、机器人姿态和唯一轮次绑定；过期响应、无效选项、拒答、超时、网络故障和目标失效均停止或重新观察，不执行旧决定。
- 记录模型输入的必要摘要、选项、响应时间、选择、保护触发、执行状态及实际位移，区分模型选择、执行器动作和真实观测；保留手动停止入口。

## 验证顺序和完成条件

1. 单元和协议测试覆盖候选筛选、停止、过期、故障处理、运动边界和回执关联；用静态图像完成 Decisions API 集成。
2. 在模拟或可重放观测中检验动态障碍、盲区、传感器中断、延迟、进程退出和急停。仿真结果不作为实机安全证明。
3. 实机只读检查设备权限、急停、模式、传感器和实时执行器边界；修复当前 `boundary_ready=false` 和操作员确认服务不可用的问题。现场活动边界、旁站和急停方式在首次运动前落实。
4. 在机器人自己的授权链内先 SHADOW、再现场确认单次低速短步；以执行回执和观测核实停止距离。逐步扩展到有界任务，只有全部停止条件经验证后才允许持续探索。

## 当前已知状态

LIMO 的激光、底盘、RGB 和深度流已观测到，底盘上报四轮差速模式；ROSClaw 当前为 DISARMED，操作员确认服务未连接。现有 REAL 执行器是地图约束的导航目标，不提供无地图连续探索。Decisions API 已完成现场图像和传感器摘要的只读试验，尚未驱动实机运动。

现场雷达只能观察前方部分角度，后方保持未知；现有候选控制器在转弯时要求后方数据，且当前左右扇区划分也不能由前向扫描完整覆盖，因此不能用当前配置完成连续探索。后续需要依据前向视野、车体轮廓和可验证的短期运动记忆重新设计动作的几何覆盖，不能将空缺视作障碍物不存在。相机深度与雷达的空间对照仍未验证，底盘独立命令丢失停车与持续运动链也未完成现场验证。

2026-11-19 只读数据中雷达最小有效距离为 0.10 米，运行时 TF 声明其位于 `base_link` 前方 0.105 米；差速示例配置中的车体前缘为 0.16 米。仅按这些尚未实测核对的参数估算，车头正前方约 0.045 米不在雷达最小有效距离之外。前向几何试验已能区分直行新增扫掠区和后方未知区，但合成栅格不能证明真实盲区已被相机或其他传感器覆盖。
